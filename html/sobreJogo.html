Modo História

História

Você controla um(a) aventureiro(a) que aceita uma missão para encontrar uma lendária mina de ouro, um lugar cercado por mistérios, lendas e desaparecimentos inexplicáveis.

Enfrente os perigos que surgirem, derrote inimigos e descubra os segredos escondidos nas profundezas da mina.

Objetivo

  • Derrotar os inimigos.
  • Sobreviver.
  • Coletar ouro.
  • Passar de fase.

Gameplay

  • Os inimigos aparecem continuamente.
  • Eliminar inimigos concede pontos.
  • Moedas podem ser coletadas.
  • Ao atingir a pontuação necessária você avança de fase.

Sistema de Combate

  • Os disparos são realizados pressionando a tecla ESPAÇO.
  • Cada inimigo possui uma quantidade diferente de resistência.
  • Os inimigos a cavalo precisam de 2 tiros para serem derrotados.
  • Os demais inimigos precisam de apenas 1 tiro.
  • Os coiotes não podem ser derrotados com tiros; é necessário desviar deles.
  • Derrote os inimigos para acumular pontos e coletar ouro.

Sistema de Vidas

Você inicia com cinco vidas.

Se todas acabarem, será possível utilizar moedas para comprar novas vidas.

Controles

  • <- → Esquerda
  • -> → Direita
  • Seta → Pular
  • Espaço → Atirar
  • Pausar → Botão superior
  • S → Pular diálogos
